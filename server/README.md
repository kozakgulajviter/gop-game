# ГОП — кімнати для двох

Окремий Worker ai1ok-gop-rooms; не має прив’язки до D1, кабінетів, AI або платежів порталу. SQLite Durable Object на кімнату, WebSocket hibernation, 24 години зберігання, потім alarm видаляє стан. Хост і гість мають різні випадкові ключі; запрошення не дає доступу до місця хоста. У повідомленнях про стан немає ключів. Запити мають версію та ID для захисту від повторів.

Клієнт: https://kozakgulajviter.github.io/gop-game/friend.html
Сервер, який слід перевірити після розгортання: https://ai1ok-gop-rooms.ai1okportal.workers.dev

Встановлення: pnpm install; перевірка: node --test ../tests/network.test.mjs; запуск: pnpm exec wrangler dev; розгортання власником: pnpm exec wrangler deploy. Потрібен авторизований Cloudflare акаунт AI1OK. Не змінювати чинний Worker порталу або його прив’язки. Платний тариф не підключати автоматично.

Перший тест: два різні браузери/профілі, створити кімнату, відкрити запрошення другим, обом натиснути Готовий, виконати ходи, перезавантажити вкладку, підтвердити дострокове завершення. Третє місце заборонене. Фізичний планшет перевіряє власник окремо.

Мінімальні дані: псевдоніми до 24 символів, ключі місць/запрошення, версія, поле, кубики, останні 30 повідомлень про ходи. На пристрої залишається ключ повернення. Імена/кімнати не пов’язані з акаунтами порталу. Видалення серверного стану через 24 години не видаляє локальний запис браузера. Підрахунок створень обмежений 10 на годину на хеш IP; лічильник видаляється через годину. Інфраструктурні логи провайдера мають окремі правила.

Обчислення й коротке зберігання належать Cloudflare-акаунту власника, показ поля — пристроям гравців. Вартість залежить від чинного плану й квот; постійного опитування D1 немає. Закритий браузер не є підключеним гравцем. Мережеві ходи офлайн не виконуються.
